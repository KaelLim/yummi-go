## 2. AI 飲食打卡流程（`src/routes/check-in/`）

### 流程

```
home → 點下一餐打卡 → capture（拍照）
                          → scanning（AI 分析中）
                          → result（結果頁 + 編輯）
                                ├─ success（+XP 慶祝頁）
                                └─ fail（失敗：含肉 / 信心度低 / 非食物）
```

### Result 頁新增「營養建議寵物對話」

打卡確認後，**根據該餐三大營養素由寵物給建議**：

```
判斷邏輯（單餐 + 絕對門檻克數）：
- 總熱量 < 150 kcal → 「主人只吃一點點呢，會餓嗎？」
- 蛋白質 < 12g → 「我下一餐想吃 [蛋白質料理] 哦～」
- 碳水 < 35g → 「下一餐來個 [碳水料理] 吧～」
- 脂肪 < 10g → 「想吃 [脂肪料理] ⋯」
- 全部達標 → 「Yummy～主人我超滿足！」
```

詳細料理池與對話池見 `docs/spec/文案資料庫.md` 第 4.17 區塊。

⚠️ **門檻克數待營養師確認後正式上線**。

### Success 頁（+XP 慶祝頁）

**通用 logo 動畫**（不分寵物，省美術成本）：

```
[+20 XP 大字]
[Logo 動畫]
[Continue 按鈕]
```

→ Continue 行為依「Gem 顯示流程」（見第 3 區）

### Fail 頁

3 種失敗情境：

1. **偵測到肉** — 「這餐看起來有肉⋯下次拍蔬食吧！」
2. **AI 信心度低** — 「我們不太確定這是食物，請確認」+ 兩按鈕（確定是 / 重拍）
3. **非食物** — 「這看起來不是食物，請拍今天的餐點」+ 重拍

## 4. 寵物系統（`src/components/PetView.ts`）

### 寵物管理規則（5/18 新增）

| 規則 | 內容 |
|---|---|
| 寵物名稱顯示 | 在**寵物主頁**（不在用戶頁）|
| 用戶名稱顯示 | 在**用戶頁**（不在寵物主頁）|
| 寵物命名 | **完成後不可更改** |
| 主頁寵物切換 | **不可切換**，只能養目前獲得的那隻 |
| 寵物圖鑑 | **需要一區塊顯示已獲得的所有寵物**（建議放 Profile / User 頁）|

### 7 種狀態（已決議）

| 狀態 | 觸發 | 解除 |
|---|---|---|
| 一般 Normal | 預設 / 完成 XP 任務後 | — |
| 開心-持續 Sustained Happy | 達當日 100 XP | 隔天 00:00 → 一般 |
| 短暫開心 Brief Happy（疊加層） | 完成任何 XP 任務後 **3-5 秒** | 自動回原狀態 |
| 飢餓 Hungry（疊加層） | 用餐時間 ±60min 未該餐打卡 | (a) 打卡 → 解除 / (b) 3 餐都打卡 → 當天不再啟動 / (c) 時段過 → 回底層 |
| 無聊 Bored | 24-72hr 無 XP 任務 | 完成任何 XP 任務 → 一般 |
| 虛弱 Weak | ≥72hr 無 XP 任務 | 完成 XP 任務 OR 用 Gem 補簽 → 一般 |
| 中毒 Poisoned | 累計 3 次惡意檢舉違規 | 連續 3 天打卡 + 1 評論 |

完整邏輯見 `docs/spec/寵物狀態邏輯.md`。

### XP 任務定義

✅ 算 XP 任務（會清除無聊 / 虛弱）：
- AI 拍照打卡
- Daily Quest（每日問答）
- Daily 幸運色
- 地圖驗證
- 留評論

❌ 不算 XP 任務：
- 永續任務 5R（不給 XP，只給寵物對話 + 動畫）
- 點寵物 / 滑地圖 / 純瀏覽

### 寵物進化（5/18 新增考量）

- **First Pet**：30 天 / 5 階段（Egg LV1-5、Baby LV6-12、Youth LV13-19、Teenager LV20-26、Max LV27-30）
- **Next Pet 以上**：**60 天 / 不同角色** / 用 Gem 解鎖
- 估算：1 年至少 6 隻寵物，3 年 18 隻 → 動畫量大

### 動畫策略（⚠️ 待 Jun 評估）

考慮拆分 2 種動畫：

- **固定式動畫**（不分寵物）：Gem 飛入、慶祝 confetti、+XP 飄字、進化光暈
- **寵物關聯動畫**（依寵物變化）：每隻寵物的 5 階段 idle + 5 種狀態

→ 跟 Jun 評估「1 隻寵物總共需要多少動畫」後再決定產出策略。

### 重要結構變更

**之前**：補簽是 tasks 頁面下的 segment
**現在**：補簽**直接在月曆頁面**操作（點灰色點觸發 modal）

### 月曆視覺

```
2026 年 5 月

日  一  二  三  四  五  六
            1   2

3   4   5   6   ●  ●  ●     ← 灰色點：可補簽
●  ●   12  13  14         ← 灰色點
15  16  ...

🟢 綠色 ✓：已打卡 / 已補簽（永久保留）
⚪ 灰色：過去 3 個日曆日內，可補簽
🔢 普通數字：歷史日期 OR 已 lost
```

### 補簽 Modal

```
┌────────────────────────────────┐
│         🐣（寵物動畫）            │
│  「主人，5/11 那天我等了你⋯」      │
│                                  │
│  ┌──────────────────────┐       │
│  │ Streak 變化預覽         │       │
│  │  目前：🔥 X 天          │       │
│  │  ↓                   │       │
│  │  補完後：🔥 Y 天（+N）✨ │       │
│  └──────────────────────┘       │
│                                  │
│  💎 100 能量石                    │
│  你目前有 💎 [N]                  │
│                                  │
│  [💛 救回那一天]    [取消]         │
└────────────────────────────────┘
```

### 規則摘要

- **沒有「卡」道具**，直接 Gem 付款
- **Gem 價格（每月重置）**：
  - 當月第 1–3 次：100 Gem
  - 當月第 4 次起：300 Gem
- **連續 4 天 missed → streak 死亡**，所有未補簽灰色點變普通數字
- 補簽**不給 XP / 不給 Bonus**，只保護 streak

完整規則見 `docs/spec/補簽機制規格.md`。

## 13. 全域文案約定

### 寵物對話原則

- **寵物視角**：寵物說「我想吃 X」，不是「你應該吃 X」
- **不下醫療判斷**：不說「您的蛋白質不足」，說「我下一餐想吃豆腐」
- **具體料理而非食材**：「麻婆豆腐」而非「豆腐」
- **撒嬌語氣**：陪伴感、有溫度

### 幸運色文案（5/18 調整）

「**照片裡有顏色就可以**」— 文案敘事方式需修改：

| ❌ 之前 | ✅ 改為 |
|---|---|
| 「拍到主色為紅色的食物」 | 「在餐點裡找到紅色就可以喔～」 |
| 「主色辨識」 | 「找到色彩」 |

→ 寬鬆敘事，鼓勵用戶尋找而非追求精準。

### 雙語策略

- **繁體中文**為主
- **英文**為次（上線即雙語）
- Gem 暫時雙語並用「Gem / 能量石」
