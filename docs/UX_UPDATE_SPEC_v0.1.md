## 1. Home Page（`src/routes/home.ts`）

### 目標

簡潔的寵物中心畫面：**2 個資源指標 + 寵物 + 任務入口**

### 元件清單

```
┌──────────────────────────────────┐
│  💎 Gem · 🔥 Streak              │  ← Top bar（2 個指標）
├──────────────────────────────────┤
│  🍀 今日幸運色：紅 →               │  ← Lucky Color prompt
│                                  │
│  💬 「主人，早安！」                │  ← 寵物對話泡泡
│                                  │
│  Eco-Mon · LV.1                  │  ← 寵物名 + 等級
│  ━━━░░░░░░░ 0/30 XP              │  ← XP 進度條
│                                  │
│        🐣 寵物 idle               │  ← 寵物（依狀態變化）
│                                  │
├──────────────────────────────────┤
│  今日任務          show more →    │
│  🍽️ 下一餐打卡        +20 XP →    │  ← 主要任務
│  🧪 每日問題          +15 XP →    │
├──────────────────────────────────┤
│ [🏠][🗺][📷][📋][👤]              │  ← Bottom nav
└──────────────────────────────────┘
```

### 行為

| 元件 | 互動 |
|---|---|
| 寵物 | 點擊 → 觸發隨機對話泡泡 |
| 寵物對話泡泡 | 依時段（早 / 中 / 晚 / 深夜）+ 寵物狀態變化 |
| Lucky Color 卡片 | 點擊 → `/check-in`（暗示「去拍幸運色食物」）|
| 「下一餐打卡」 | 點擊 → `/check-in` |
| 「每日問題」 | 點擊 → `/tasks/quiz` |
| 「show more」 | 點擊 → 跳到任務 tab |

### 差異（從現有 prototype 更新）

| 項目 | 現有 | 變更 |
|---|---|---|
| Top bar 指標 | XP / Gem / **補簽卡** 3 個 | 移除 XP 與補簽卡，**只留 Gem + Streak** |
| Streak 顯示 | 無 | **新增** 🔥 Streak 到 top bar |
| 容錯 pill | 有 `tolerance-pill` | **移除** |
| 今日進度卡 | D1/30 + 容錯 + 三餐 dots | 整合進「任務」卡片或移除（依本頁版面） |
| 寵物對話 | 「守護者氣息微弱⋯」單一文案 | 改為**依時段 / 狀態變化**的對話池 |

### 寵物狀態對應視覺

寵物角色會依 7 種狀態變化（詳見 `docs/spec/寵物狀態邏輯.md`）：

- 一般（Normal）— idle 動畫
- 開心-持續（Sustained Happy）— 達 100 XP 後到午夜
- 短暫開心（Brief Happy）— 完成 XP 任務後 30 秒
- 飢餓（Hungry）— 用餐時間 ±60min 未打卡
- 無聊（Bored）— 24-72hr 無 XP 任務
- 虛弱（Weak）— ≥72hr 無 XP 任務
- 中毒（Poisoned）— 累計 3 次惡意檢舉違規

## 2. AI 飲食打卡流程（`src/routes/check-in/`）

### 流程

```
home → 點下一餐打卡 → capture（拍照）
                          → scanning（AI 分析中）
                          → result（結果頁 + 編輯）
                                ├─ success（+XP 慶祝頁）
                                └─ fail（失敗：含肉 / 信心度低 / 非食物）
```

### Result 頁新增「營養建議寵物對話」

打卡確認後，**根據該餐三大營養素由寵物給建議**：

```
判斷邏輯（單餐 + 絕對門檻克數）：
- 總熱量 < 150 kcal → 「主人只吃一點點呢，會餓嗎？」
- 蛋白質 < 12g → 「我下一餐想吃 [蛋白質料理] 哦～」
- 碳水 < 35g → 「下一餐來個 [碳水料理] 吧～」
- 脂肪 < 10g → 「想吃 [脂肪料理] ⋯」
- 全部達標 → 「Yummy～主人我超滿足！」
```

詳細料理池與對話池見 `docs/spec/文案資料庫.md` 第 4.17 區塊。

⚠️ **門檻克數待營養師確認後正式上線**。

### Success 頁（+XP 慶祝頁）

**通用 logo 動畫**（不分寵物，省美術成本）：

```
[+20 XP 大字]
[Logo 動畫]
[Continue 按鈕]
```

→ Continue 行為依「Gem 顯示流程」（見第 3 區）

### Fail 頁

3 種失敗情境：

1. **偵測到肉** — 「這餐看起來有肉⋯下次拍蔬食吧！」
2. **AI 信心度低** — 「我們不太確定這是食物，請確認」+ 兩按鈕（確定是 / 重拍）
3. **非食物** — 「這看起來不是食物，請拍今天的餐點」+ 重拍

## 3. Gem 顯示流程（跨多個 routes）

### Pre-100 XP（工作模式）

```
任務完成 → +XP 慶祝頁 → Continue → 返回原本來的頁面
（不強制回首頁，保持流暢度）
```

### 跨 100 XP（模式切換 + 首次達標）

```
任務完成 → +XP 慶祝頁 → Continue → 強制返回 Home
                       ↓
                Home 顯示：
                - XP bar 動畫到 100
                - 大慶祝動畫（3 秒）
                - 1 Gem 飛入頂部 💎
                - 寵物進入「持續開心」狀態
                - 【首次達標當天】Educational popup：
                  「主人達標了！從現在開始，每個任務都會為你換成 Gem 💎」
```

### Post-100 XP（慶祝模式）

```
任務完成 → +XP 慶祝頁 → Continue → 強制返回 Home
                       ↓
                Home 顯示：
                - Overflow Gem 動畫（1.5 秒）
                - 💎 數字快速跳動
```

### 動畫策略

- **Pet-specific Lottie**：normal / happy / hungry / bored / weak / evolution
- **通用覆蓋動畫**（不分寵物）：Gem 飛入、Confetti、Overflow 粒子
- **所有動畫可點擊跳過**

## 4. 寵物系統（`src/components/PetView.ts`）

### 7 種狀態

| 狀態 | 觸發 | 解除 |
|---|---|---|
| 一般 Normal | 預設 / 完成 XP 任務後 | — |
| 開心-持續 Sustained Happy | 達當日 100 XP | 隔天 00:00 → 一般 |
| 短暫開心 Brief Happy（疊加層） | 完成任何 XP 任務後 30 秒 | 自動回原狀態 |
| 飢餓 Hungry（疊加層） | 用餐時間 ±60min 未該餐打卡 | 打卡 OR 時段過 |
| 無聊 Bored | 24-72hr 無 XP 任務 | 完成任何 XP 任務 → 一般 |
| 虛弱 Weak | ≥72hr 無 XP 任務 | 完成 XP 任務 OR 用 Gem 補簽 → 一般 |
| 中毒 Poisoned | 累計 3 次惡意檢舉違規 | 連續 3 天打卡 + 1 評論 |

完整邏輯見 `docs/spec/寵物狀態邏輯.md`。

### XP 任務定義

✅ 算 XP 任務（會清除無聊 / 虛弱）：
- AI 拍照打卡
- Daily Quiz
- Daily 幸運色
- 地圖驗證
- 留評論

❌ 不算 XP 任務：
- 永續任務（不給 XP，只給寵物對話）
- 點寵物 / 滑地圖 / 純瀏覽

### 寵物進化

- **First Pet**：30 天 / 5 階段（Egg LV1-5、Baby LV6-12、Youth LV13-19、Teenager LV20-26、Max LV27-30）
- **Next Pet**：60 天 / 不同角色 / 用 Gem 解鎖

## 5. 月曆 / 補簽（從 `src/routes/tasks/makeup.ts` 搬到月曆頁面）

### 重要結構變更

**之前**：補簽是 tasks 頁面下的 tab
**現在**：補簽**直接在月曆**頁面上操作（點灰色點觸發 modal）

### 月曆視覺

```
2026 年 5 月

日  一  二  三  四  五  六
            1   2

3   4   5   6   ●  ●  ●     ← 灰色點：可補簽
●  ●   12  13  14         ← 灰色點
15  16  ...

🟢 綠色 ✓：已打卡 / 已補簽（永久保留）
⚪ 灰色：過去 3 個日曆日內，可補簽
🔢 普通數字：歷史日期 OR 已 lost
```

### 補簽 Modal

```
┌────────────────────────────────┐
│         🐣（寵物動畫）            │
│  「主人，5/11 那天我等了你⋯」      │
│                                  │
│  ┌──────────────────────┐       │
│  │ Streak 變化預覽         │       │
│  │  目前：🔥 X 天          │       │
│  │  ↓                   │       │
│  │  補完後：🔥 Y 天（+N）✨ │       │
│  └──────────────────────┘       │
│                                  │
│  💎 100 能量石                    │
│  你目前有 💎 [N]                  │
│                                  │
│  [💛 救回那一天]    [取消]         │
└────────────────────────────────┘
```

### 規則摘要

- **沒有「卡」道具**，直接 Gem 付款
- **Gem 價格（每月重置）**：
  - 當月第 1–3 次：100 Gem
  - 當月第 4 次起：300 Gem
- **連續 4 天 missed → streak 死亡**，所有未補簽灰色點變普通數字
- 補簽**不給 XP / 不給 Bonus**，只保護 streak

完整規則見 `docs/spec/補簽機制規格.md`。

## 9. 全域文案約定

### 寵物對話原則

- **寵物視角**：寵物說「我想吃 X」，不是「你應該吃 X」
- **不下醫療判斷**：不說「您的蛋白質不足」，說「我下一餐想吃豆腐」
- **具體料理而非食材**：「麻婆豆腐」而非「豆腐」
- **撒嬌語氣**：陪伴感、有溫度

### 暫定文案標記

所有畫面內含 XP / Gem / Streak / 補簽 等通用字眼者，未來會替換為世界觀名稱。**Prototype 階段不需強制改**，等命名定案後一次性更新。

### 雙語策略

- **繁體中文**為主
- **英文**為次（上線即雙語）
- Gem 暫時雙語並用「Gem / 能量石」
